# MTG Free — Android Release Channel

Public Obtainium source for the **MTG Free** Android app (signed APK, Capacitor hybrid wrapper).

The source code lives in the private [`xeroneon/mtg-free`](https://github.com/xeroneon/mtg-free) repo;
this repository is a **release-only channel** hosting the signed `mtg-free-v<version>.apk`
assets so [Obtainium](https://obtainium.imranr.dev/) can install/update the app anonymously.

## Obtainium source config

- **Type:** GitHub
- **Source:** `xeroneon/mtg-free-releases`
- **What to install:** `mtg-free-v[.0-9]+\.apk`
- **Version check:** By release tag name
